ADD YOUR OWN 'OUR STORY' PHOTOS HERE
------------------------------------
Copy your photos into this folder (jpg, jpeg, png, webp). That's all - no code changes.
They appear as a slideshow behind the rotating fabric cards in the Our Story section,
in file-name order (1.jpg, 2.jpg, 3.jpg ...). One photo = static background.

Best size: 1200 x 1200 px (square), subject in the centre, under ~300 KB each.
Restart 'npm run dev' if the dev server was running when you added the first photo.
